Cooked mods

Drop a mod .zip here — one containing the cooked .utoc and .ucas (a companion .pak is optional; the manager adds a verified stub if it's missing). The manager keeps a hash-checked backup and never overwrites a file.

Mod descriptions and thumbnails

Add these optional files to the root of your mod ZIP, alongside the cooked .utoc and .ucas files:

  • INFO.txt — plain UTF-8 text. Its contents appear as the mod description in this launcher. Keep it to 16 KB or less.
  • THUMB.png, THUMB.jpg, THUMB.jpeg, or THUMB.webp — displays an image beside the mod. The image must be 1 MB or smaller.

Both are optional. Use the exact base names INFO.txt and THUMB; image extensions are case-insensitive. These files are metadata only and are not installed into the game.

Reversible staging, not a patcher. The manager copies only into GZPro\Content\Paks\LogicMods. Disable removes only the manager's verified copies; its backup stays in your local app-data folder.

It never edits the game's original .pak, .utoc, or .ucas archives. Blueprint mod loading is handled by UE4SS's BPModLoaderMod, which must be installed separately. Asset override mods do not require UE4SS. A raw WAV must first be cooked into an IoStore mod package.
