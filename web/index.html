The manager packages the cooked container for installation as an asset override, with the normal backup and enable/disable controls. It does not repack or rename assets inside the Unreal container.

Reversible staging, not a patcher. The manager copies only into GZPro\Content\Paks\LogicMods. Disable removes only the manager's verified copies; its backup stays in your local app-data folder.

It never edits the game's original .pak, .utoc, or .ucas archives. Blueprint mod loading is handled by UE4SS's BPModLoaderMod, which must be installed separately. Asset override mods do not require UE4SS. A raw WAV must first be cooked into an IoStore mod package.
