Mods

Drop a supported mod .zip anywhere in the window. Supports cooked containers, UE4SS character and skin packages, GZSkinLoader packages, and optional DLL installation. Every installed file is backed up and different existing files are never overwritten.

Mod descriptions and thumbnails

Add these optional files to the root of your mod ZIP. They work with standard packages and combined skin-loader packages:

  • INFO.txt — plain UTF-8 text. Its contents appear as the mod description in this launcher. Keep it to 16 KB or less.
  • THUMB.png, THUMB.jpg, THUMB.jpeg, or THUMB.webp — displays an image beside the mod. The image must be 1 MB or smaller.

Both are optional. Use the exact base names INFO.txt and THUMB; image extensions are case-insensitive. These files are metadata only and are not installed into the game.

Troubleshooting

Common problems, what causes them, and the safest fix.

Unsupported file or folder in the package

Cause: The ZIP has a folder layout or file type the manager does not recognize.

Fix: Keep the mod's original folder structure. UE4SS packages can include GZPro/Binaries/Win64/dwmapi.dll and files inside GZPro/Binaries/Win64/ue4ss/.

Character or skin does not appear

Cause: UE4SS did not load, the game is using an incompatible loader build, or the mod's script did not register.

Fix: This game uses Unreal Engine 5.8 and needs the compatible experimental UE4SS build. Check for dwmapi.dll and ue4ss/UE4SS.dll beside the game executable. Check ue4ss/UE4SS.log for the mod name or an error.

dwmapi.dll already exists

Cause: Another UE4SS installation or mod already uses the Windows DLL loader slot.

Fix: Do not overwrite it blindly. Compare the installed UE4SS version with the one required by the mod. One game installation can only use one dwmapi.dll at a time.

The package is missing .utoc or .ucas

Cause: A cooked IoStore mod is missing one of its required container files.

Fix: Download the complete mod archive. The matching .utoc and .ucas files are required; a companion .pak is optional.

The game is running

Cause: The game may have files open, so changing them could corrupt an installation.

Fix: Exit the game completely before importing, enabling, disabling, replacing, or deleting mods.

Windows says access is denied

Cause: Windows permissions or another program is blocking the file operation.

Fix: Close the game and other mod tools. Make sure the game folder and %LOCALAPPDATA%\GZProModManager are writable.

The game crashes after installing UE4SS

Cause: UE4SS may be the wrong build for this game version, or a mod may be incompatible.

Fix: Disable the affected mod. If the game still crashes, temporarily remove or rename dwmapi.dll to disable UE4SS, then check the UE4SS log and mod requirements.

Mod replacement or deletion is blocked

Cause: A game file no longer matches the manager's verified copy, or its backup is missing.

Fix: The manager leaves changed files untouched to avoid deleting someone else's work. Do not force-delete them; copy the exact error details and report the issue.

If the listed fix does not solve it, use Copy error details beneath the error and include them when you report a bug.

Reversible staging, not a patcher. The manager copies supported mod files into their recognized game folders. Disable removes only the manager's verified copies; its backup stays in your local app-data folder.

It never edits the game's original .pak, .utoc, or .ucas archives. Blueprint mods use UE4SS's BPModLoaderMod. UE4SS-based character and skin packages may include the loader files; only install DLLs and scripts from sources you trust. Asset override mods do not require UE4SS. A raw WAV must first be cooked into an IoStore mod package.
