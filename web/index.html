Cooked mods

Drop a mod .zip here — one containing the cooked .utoc and .ucas (a companion .pak is optional; the manager adds a verified stub if it's missing). The manager keeps a hash-checked backup and never overwrites a file.

Reversible staging, not a patcher. The manager copies only into GZPro\Content\Paks\LogicMods. Disable removes only the manager's verified copies; its backup stays in your local app-data folder.

It never edits the game's original .pak, .utoc, or .ucas archives. Loading is handled by UE4SS's BPModLoaderMod — verified working on this game — which must be installed separately. A raw WAV must first be cooked into an IoStore mod package.
